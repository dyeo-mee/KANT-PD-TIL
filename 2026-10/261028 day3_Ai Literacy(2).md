## 1. AI의 한계와 답변 검증
- 할루시네이션 (Hallucination)
    - 사실이 아닌 내용을 사실처럼 만들어 내는 것.<br>
    → AI가 점수를 많이 받기위해 생기는 현상.

- 4가지 유형
    - 할루시네이션 : 없는 사실을 그럴듯하게 지어냄
    - 지식 컷오프 : 학습 이후의 변화를 모름
    - 편향 : 데이터의 치우침을 따라감
    - 맥락 오해 : 질문의 뜻을 다르게 읽는다

- 아첨 - 사용자가 듣고싶어 하는 쪽으로 답을 맞추는 것.
    > 비판할 자리를 먼저 만드는 것이 중요.
    - bad : 이 예약 화면 디자인 괜찮지? → 네, 아주 깔끔하고 좋아요!
    - good : 이 예약 화면의 문제점 3개를 알려줘. → 네, 첫번째로 …(생략)

- AI의 잘못된 활용 사례
    1. 가짜 판례 : 존재하지 않는 판례가 법원 서면에 들어감. (2023)
    2. 챗봇 안내 책임 : 항공사 챗봇이 유족 할인 규정을 실제와 다르게 안내함. (2024)
    3. 가짜 인용 보고서 : 44만 호주달러 규모의 보고서에 존재하지 않는 논문 인용과 지어낸 판결문 인용이 들어가있었다. (2025)
    4. 이미지 편향 : 직업 14개에 대해 얼굴 이미지를 300장씩 만들어 성별, 피부색을 분석했으나 판사의 이미지 중 여성은 3%에 불과(하지만 실제 미국 판사의 34%가 여성)

- 답변 검증 3단계<br>
    1단계. 쪼개기 - 숫자, 날짜, 이름, 인용이 들어간 문장을 하나씩 떼어낸다<br>
    (한 문장에 여러 사실이 포함돼있으면 각각 분리하기.)<br>
    2단계. 1차 출처 찾기 - 출처를 요구하고 내용을 처음 발표한 곳에서 직접 확인하기<br>
    (공식 기관, 원문 자료, 학술 논문 등 신뢰도 높은 출처를 찾아 확인.<br>
    또한, AI가 제시한 출처가 실제 존재하는지, 내용이 설명과 일치하는지 확인한다.)<br>
    3단계. 판정 + 확인일 - 맞음, 틀림, 확인 불가로 판단<br>
    - 확인됨: 신뢰할 수 있는 자료에서 사실을 확인했다
    - 불일치: 출처의 내용과 AI의 설명이 다르다.
    - 확인 불가: 근거를 찾지 못 했거나 추가 확인이 필요하다.

    >AI가 출처를 제시했다고 해서 신뢰도 높은 답변이 되지 않음.<br>
    출처가 실제로 존재한다 한들, 해당 내용이 인용된 문장을 뒷받침하는지 확인이 필수.

## 2. 책임있는 AI 활용과 나만의 가이드
- 체감 성과와 실제 성과<br>
    : ai를 더 믿는 사람일수록 비판적 사고를 덜 함 <> 내 실력을 믿을수록 비판적 사고는 높음 ^

- 맡길 일과 배울 일<br>
    | AI에게 맡길 일 | 내가 먼저 해볼 일 |
    |---|---|
    | 회의 메모를 정해진 형식으로 정리 | 사용자 흐름 직접 그려보기 |
    | 문구 변형 10개 뽑기 | 화면의 문제점 먼저 찾기 |
    | 긴 자료의 요약 초안 | 리서치 질문 직접 만들기 |


- 이해를 확인하는 질문
    1. 설명하고 검사받기: 개념을 배운 직후
    2. 힌트만 받기: 실습, 과제를 할 때
    3. 약한 고리 찾기: 내 디자인 결정을 점검할 때
    4. 내 예시로 바꾸기: 배운 걸 실무로 옮길 때
    - 닫힌 질문이 아닌 사고를 확장하는 질문 생활화<br>
    - 먼저 답을 쓰려는 습관을 들이고 AI의 답변을 비교해 다른점 보완하기

- 넣으면 안되는 정보와 저작권
    > 직원들이 소스 코드와 회의 내용을 ChatGPT에 입력한 사례
    - **비식별 데이터로 변경하기**<br>

    | 종류 | 예시 | 대신 이렇게 사용하기 |
    |---|---|---|
    | 개인정보 | 사용자 이름, 연락처가 들어간 인터뷰 원본 | 이름대신 P1, P2로 바꾸고 식별정보 지우기|
    | 회사 기밀 | 미공개 기획서, 내부 수치, 소스 코드 | 회사가 허용한 도구, 계정에서만 사용 |
    | 계약상 비공개 | 클라이언트 자료, 비밀유지계약대상 | 담당자에게 먼저 확인 |
    | 인증 정보 | 비밀번호, API 키, 토큰 | 어떤 경우에도 넣지 않기 |

    - 저작권<br>
        : AI 결과물을 공개하거나 상업적으로 이용하기 전 기존 작품과 유사한 부분이 있는지 확인하고, 문제가 의심되면 수정하거나 권리자의 허락을 받아야 함.<br>
        -> 출처를 표시하는 것과 이용 허락을 받는 것음 엄연히 다르므로 구분할 것.<br>
        1. 입력 전: 타인의 저작물이나 비공개 자료를 AI에 입력해도 되는지 확인.
        2. 생성 후: 결과물이 기존 저작물과 유사하지 않은지, 이용 조건에 문제 없는지 확인.
        3. 공개 전: 출처, 라이선스, 저작권 및 관련 권리, 기관의 AI 사용 규정을 확인.
        4. 사용 사실 밝히기<br>
        - 투명성: AI를 사용했다는 사실을 숨기지 않는다.
        - 구체성: 사용 도구와 활용 범위를 명확히 밝힌다.<br>
