## 1. Auto Layout 방향/간격/패딩
- 수동배치의 문제<br>
    : 절대위치로 놓은 요소는 서로를 모른다! 글자가 늘면 서로 겹치거나 넘침.

- Auto Layout {shift + A}
    - 방향: 다음 요소가 쌓이는 축. 세로 가로
    - 간격: 자식 요소끼리의 거리를 직접 조정 (8의 배수로 설정)
        - auto: 양 끝에 요소를 배치해야 할 때, 자동으로 간격을 조정.
    - 아주 작은 단위 요소부터 하나씩 번위를 늘려가며 오토 레이아웃을 만들어감.

- 패딩과 정렬
    - 패딩: 프레임 테두리와 내용 사이의 여백 ex.버튼, 카드, 섹션<br>
    (상하좌우 4방향을 각각 설정 가능함)<br>
    -> 요소에 Stroke가 있는 경우 옵션에 따라 패딩 값이 달라질 수 있음<br>
    (Stroke의 3가지 옵션: center, inside, outside)
    - 정렬: 프레임 안에서 내용이 붙는 위치

- Constraints과 Auto Layout의 차이
    - Constraints : 부모 프레임을 기준으로 자식 요소가 어떤 위치를 유지할지 정하는 기능.<br>
    ex. 화면 너비가 달라져도 닫기 버튼이 항상 오른쪽 상단에 위치하도록 설정하는 경우.
    - Auto Layout : 요소간의 배치 규칙과 간격, 여백, 크기 조정 방식을 콘텐츠 변화에 자동으로 대응하도록 만드는 기능<br>
    → 디바이스 크기 뿐 아니라 텍스트 길이, 콘텐츠 개수, 요소의 크기 등이 달라질 때도 요소의 배치를 자동으로 조정

## 2. 사이즈 설정 Hug/Fixed/Fill
- 사이즈를 정하는 옵션 3가지
    - Hug: 자식 요소가 부모 요소의 크기를 결정<br>
    → 내용의 사이즈만큼 부모 사이즈가 조정됨
    - Fixed: 숫자로 정해둔 값 → 요소의 내용이 늘어나도 사이즈는 동일(내용이 넘침)
    - Fill: 부모요소의 사이즈를 이어 받음 → 자식 요소의 내용이 작아도 남는 공간에 채워짐
        - align: 컨텐츠 요소가 어디에 위치해야할지 신경써 주어야함!
        - 정보의 길이가 길어질 상황을 위해 디자인 당시 내용이 짧아도 fill로 디바이스 크기만큼 채워줘야 함
        - Fill은 부모가 Auto Layout이어야 설정 가능.
        -> Hug는 자기 자신이 Auto Layout이어야 보인다.

- 텍스트 사이즈<br>
    : auto width는 줄바꿈이 안돼서 긴 제목이 한 줄로 삐져나감.<br>
    → 따라서 여러줄이 될 내용은 Fill+Auto height로 설정하기.
    - 텍스트가 너무 길어지면 자동으로 생략해주는 기능이 존재<br>
    -> 타이포그래피 옵션의 *'turncate text'*

- 실수와 디버깅
    - 자주하는 실수
    1. Fill이 안 늘어남 : 부모가 hug라 늘어날 공간이 없음
    2. 제목이 삐져나감 : 텍스트가 auto width라 줄바꿈 안됨
    3. 넓은 화면에서 공백이 생김: 화면 너비를 따라야 할 요소가 fixed, hug 돼있는 경우.<br>
    => ***특정 요소가 원하는대로 적용이 안돼면 부모요소의 설정값 찾아보기***
